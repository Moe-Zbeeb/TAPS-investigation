# Data preparation and queue evidence

These receipts record real data preparation, target-generation startup and a guarded training queue. They are not trained-drafter quality results. Exact copied receipt hashes are in [SHA256SUMS](SHA256SUMS).

- [Corpus completion](corpus-completion.json): CPU job `2214960` prepared 540,107 grouped conversations from seven verified source files. Train/dev/test counts are 529,031 / 5,539 / 5,537. Complete original-answer conversations total 284,115. Target regeneration and native tokenization filtering were not performed by that CPU pass.
- [Teacher smoke completion](teacher-smoke-completion.json): the corrected eight-GPU real-data smoke processed 64 conversations, accepting 55 and excluding 9 responses at the generation limit. It is an engineering check. The full 540,107-input generation plan then started automatically.
- [Cluster snapshot](cluster-snapshot.json): at 13:26 UTC, all eight generation engines were ready. Their journals recorded 768 processed conversations and counts totaling 1,271,040 generated tokens, including responses later excluded by the completion policy. A read-only telemetry sample showed 93–94% GPU utilization and 68,807–70,273 MiB used on each of deep10's eight A100 80GB GPUs. The other eight-GPU allocation was finishing the independent validation screen. Instantaneous utilization is not an average throughput or training-compute measurement.
- [Partial raw recheck](partial-raw-recheck.json): CPU job `2214981` verified the completed real-model GPU artifacts. It recomputed the 60 conditional cases from their full histograms, native AR weights and registered event masks. Conditional checks passed; the 1,120-pair greedy panel retained 3 failures. This CPU replay does not generate new samples or rerun a target forward. Sampling-phase coverage and independent review are absent, so its status is correctly `blocked` and it cannot admit training.
- [End-to-end sampling summary](sampling-summary.json): all 61,440 registered continuations completed and all 36 simultaneous event comparisons passed. This bounded screen does not establish universal output-distribution equivalence.
- [Full raw replay](full-raw-recheck.json): job `2214995` independently recomputed all three completed phases. Conditional and sampling checks passed; greedy and independent-review checks remained false. Its `blocked` status preserves the training gate.
- [Queue submission](queue-submission.json): data coordinator `2214977` → data completion/timeout continuation `2214983` → CPU admission `2214978` → eight-GPU, 200-update scratch-native profile `2214979`. Admission also depends on validation/replication job `2214872`. Pending jobs reserve no GPUs. The unchanged failed original baseline and required validator review remain blocking conditions. Forty-epoch reproduction is not queued.

The training queue's active source bundle is version 6; the teacher bundle is version 3. The partial CPU replay used version 5, retained in commit `c06bd91`. Version 6 caches fixed tokenizer vocabulary sizes; full replay job `2214995` verified all three phases without changing the raw experiment or margins. Earlier version assertions and cancelled dependency jobs remain in cluster outputs. The original deployed source identity remained `6375933ffe6e688eb4eb032360eabe519efadd01e13233a56869a022bf6f2caa`; new implementations were staged separately.
