## What is supported

The ideal fixed-child residual argument is correct for exact conditional target laws, distinct ordered children chosen independently of fresh verifier draws, and an already target-selected root. Removing each rejected child's mass gives reach probability equal to remaining target mass; acceptance and fallback then recover the target categorical law. Induction covers later verified prefixes. The exact path-probability budget argument is valid with prefix closure and deterministic depth-first tie handling. It proves an ideal rule, not floating-point kernel or cache correctness, and estimated calibrator scores do not inherit the exact optimality result.

The pinned native posterior code implements ordered child trials, ignores duplicate IDs and -1 padding, and removes and renormalizes rejected mass. The collector invokes that native callable with its full native candidate paths. It scores the first token after the fixed root, rather than mistakenly auditing only initialization. `ar_reference` disables tree mode and zeros the actual cache-length data before a complete prefix forward. The reference weights are independently computed rather than copied from tree logits. The end-to-end collector uses new method/mode/prompt/repetition seeds, and `runner.seed_runtime` seeds Python, NumPy and Torch. The fixed stream mapping has 61,440 distinct end-to-end seeds. Independence is the ordinary pseudorandom-stream assumption, not something a seed uniqueness test proves mathematically.

The registered concentration calculations are coherent. The conditional radius is 0.009264057064229734 for 960 comparisons at alpha 0.025, with margin 0.02. The two-arm end-to-end radius is 0.027890595366108193 for 36 differences with 10,240 independent continuations per arm at alpha 0.025, with margin 0.06. Balanced, independent observations can have different prompt-specific expectations; the estimand is the equal-weight fixed-prompt mixture. Overlap between binary events does not invalidate the union bound. Both twice-radius inequalities support the stated at-least-97.5% joint passing probability under exact equality in each family. Together the confidence families control their specified event errors at familywise alpha at most 0.05. They do not establish full-vocabulary TV, general traffic, long-sequence equivalence or a theorem about production numerical arithmetic.

The retained CPU replay reports complete registered coverage, conditional=true, sampling=true, greedy=false and independent review=false, and its canonical identity recomputes correctly. It remains blocked. The retained end-to-end summary contains all 36 passing comparisons. Their largest reported upper bound is about 0.039414, below the registered 0.06 margin. The retained report inventories 211 artifacts. ## Findings requiring correction

1. **P1: certificate claims can authorize training without replay evidence.** `src/taps_rebuild/admission.py:57-69` accepts embedded all-true checks and `review.decision=approved`; it does not verify the actual independent review document, mandatory artifact categories or raw replay findings. `tests/test_admission.py:15-28` constructs a report over 150 arbitrary files and successfully authorizes it. A recomputable JSON self-hash is integrity metadata, not proof of the report's producer or scientific conclusion. A replacement certificate must bind the actual independent review and evidence identities, validate its exact required population/artifact schema, and require the CPU reconstruction. Implementation review approval must remain distinct from evidence-level admission.

2. **P1: final artifact verification does not verify content.** `admission.py:66-68` compares inode/size/mtime only and never compares the saved SHA256. In-place same-size edits with restored mtime survive this test. `admission.py:123-129,146-156,175-176` binds journals/captures but not all source/model/tokenizer artifacts represented inside the prepared metadata. `runner.py:133-144` verifies model file sizes and config bytes, not every model/tokenizer file, at collection. The new gate should verify SHA256 content of all required bound artifacts at admission and bind complete source, model, tokenizer, runtime, hardware and policy identities. File stat equality may be an additional diagnostic, not the content check. Preserve the original receipts and state the collection-time provenance assumptions honestly.

3. **P1: end-to-end CPU validation permits incomplete continuations and substituted tokenized inputs.** `admission.py:185-190` accepts an empty or short unterminated raw output if its comparison projection is self-consistent, and verifies input IDs only against their own row hash. It does not establish that the IDs encode the registered prompt under the frozen tokenizer/system template. Require at least 32 raw tokens unless a native terminal occurs earlier, valid vocabulary IDs, the registered inclusive terminal/cap projection, and exact frozen or independently reconstructed input IDs for every arm/repetition. The collector's prepared sampling prompts contain texts rather than the preregistered pre-draw token-ID inventory (`experiments/validation-queue-20261110/driver.py:115-122,156-160,280`). Retrospective reconstruction can audit the actual input identity but must not be described as the missing pre-draw token-ID freeze.

4. **P2: strengthen conditional tensor reconstruction.** `admission.py:72-102` should reject nonfinite/negative original weights or nonpositive mass, enforce method-specific vocabulary and tree-logit/candidate dimensions, allow only valid IDs or registered -1 padding, check the captured prefix starts with the registered rendered input and ends with its common root, and recompute the tree-versus-AR TV diagnostic from saved tensors. Presently the collector stores those tensors (`driver.py:203-224`) but the validator checks only parts of their relationships; the reported TV is not reconstructed. These repairs can use retained artifacts when those artifacts contain the required information; they need not alter the registered event definitions or budgets.

5. **P1 for numerical admission: the current near-tie report is insufficient for the proposed full-vector numerical classification.** `experiments/greedy-audit-20261110/greedy_audit.py:91-94,135-145` retains the first captured vector transiently and writes only top-five values plus full-vector discrepancy summaries. The second replay checks output identity but does not retain a second full logit vector. Thus the observed top-token sign flip is inspectable, but the maximum full-vector delta and repeated vector stability cannot be independently recomputed from retained raw vectors. The exact kernel cause is unresolved. Do not convert this diagnostic to a blanket tolerance waiver.

6. **P2: the ideal proof must remain explicitly separate from native exactness.** Pinned EAGLE `utils.py:396-400` and HASS `model/utils.py:385-389` use Python `random.random()` and `r <= acp`. A discrete PRNG draw of zero can accept a zero-probability candidate, whereas the ideal statement says it is rejected. Native finite-precision renormalization also differs from exact arithmetic. This negligible endpoint discrepancy does not invalidate the finite-margin event screen; it prevents a literal claim that every native draw is covered by the ideal exact theorem. Preserve upstream bytes and state this boundary.
